# Data

Raw Zimbabwe MICS 2019 microdata are intentionally **not stored in this GitHub repository**.

To reproduce the analysis:

1. Obtain authorised access to the Zimbabwe MICS 2019 microdata.
2. Locate the 5–17-year-old dataset (`fs.sav`).
3. Store the authorised files locally.
4. Update the notebook's loading path if required.

Do not commit raw or row-level MICS microdata to this repository.
